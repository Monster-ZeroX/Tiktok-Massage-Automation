# Contributing to TikTok Automation Bot

We welcome contributions! Please follow these guidelines to ensure a smooth process.

## Getting Started

1.  Fork the repository.
2.  Clone your fork locally.
3.  Install dependencies: `npm install`.

## Development Workflow

1.  Create a new branch for your feature or fix: `git checkout -b feature/my-new-feature`.
2.  Make your changes.
3.  Run tests to ensure nothing is broken: `npm test`.
4.  Commit your changes with clear messages.
5.  Push to your fork and submit a Pull Request.

## Code Style

- Use standard JavaScript/Node.js conventions.
- Keep functions small and modular.
- Use `async/await` for asynchronous operations.
- Ensure proper error handling and logging using the provided `logger`.

## Testing

- Write unit tests for new utility functions or configuration logic.
- Run `npm test` before submitting.

## Reporting Issues

If you find a bug, please open an issue with:
- Description of the issue.
- Steps to reproduce.
- Relevant logs (remove sensitive info).

Thank you for contributing!
